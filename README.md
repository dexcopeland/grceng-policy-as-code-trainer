# grceng-policy-as-code-trainer

GitHub Pages policy-as-code trainer scaffolded with Vite, React, TypeScript, Tailwind CSS, shadcn/ui, and Vitest.

## Development

Install dependencies:

```bash
npm install
```

Run the app locally:

```bash
npm run dev
```

Run tests:

```bash
npm test
```

Build for GitHub Pages:

```bash
npm run build
```
